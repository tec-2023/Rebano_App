# 🐑 Rebaño - Sistema de Gestión Eclesiástica

Rebaño es una plataforma móvil multi-inquilino (Multi-tenant) diseñada para modernizar la administración de iglesias cristianas. Construida para funcionar como un servicio SaaS gratuito e independiente, permite a múltiples congregaciones operar en entornos de datos aislados y seguros utilizando un solo código base.

## 🚀 Características Principales

*   **Arquitectura Multi-tenant:** Aislamiento de datos por congregación mediante códigos de acceso generados automáticamente.
*   **Sistema de Roles Acumulativos:** Gestión dinámica de permisos (Admin, Líder de Célula, Tesorero, Miembro) adaptada a la realidad eclesiástica.
*   **Gestión Celular y Evangelismo:** Control de asistencia de grupos hogareños y mapeo de rutas de evangelismo.
*   **Módulo Financiero Seguro:** Control de ingresos/egresos, respaldo fotográfico de facturas, reportes exportables a Excel y acceso restringido.
*   **Actualizaciones In-App (OTA):** Sistema de distribución independiente de APK con detección automática de nuevas versiones alojadas en la nube.

## 🛠️ Stack Tecnológico

*   **Frontend:** Flutter & Dart (Compilación nativa para Android).
*   **Backend & Base de Datos:** Supabase / Firebase (Autenticación, Storage y BDD en tiempo real).
*   **Geolocalización:** Integración con mapas para trazado de rutas.
